# Как устроен этот сайт

Это сайт-портфолио дизайнера: на одной странице собраны приветствие, услуги, опыт, проекты, отзывы, статьи и контакты. Ниже — простое объяснение, что за что отвечает.

## 1. HTML: из чего состоит страница

HTML — это каркас сайта. В `index.html` браузер получает список элементов и понимает, где заголовок, где навигация, где форма, а где основное содержимое.

В начале документа стоит `<!DOCTYPE html>` — так браузер понимает, что перед ним современный HTML. Элемент `<html lang="en">` оборачивает всю страницу; `lang="en"` сообщает браузеру и программам чтения с экрана, что текст страницы на английском. В `<head>` находятся настройки, название вкладки, описание страницы и подключения стилей, шрифтов и EmailJS. Например, `meta name="viewport"` помогает странице подстраиваться под ширину телефона.

Внутри `<body>` лежит видимая часть сайта:

- `<header>` — шапка с логотипом и навигацией.
- `<nav>` — область навигационных ссылок. В подвале у неё есть `aria-label="Footer navigation"`, чтобы было понятно, что это именно навигация подвала.
- `<main>` — главное содержимое страницы.
- `<section>` — отдельный смысловой раздел: услуги, опыт, портфолио и другие части. Заголовки `<h1>`, `<h2>`, `<h3>` задают порядок тем: обычно на странице один главный заголовок `<h1>`, а заголовки меньшего уровня относятся к разделам и карточкам.
- `<article>` — самостоятельная запись, например карточка услуги, проекта, отзыва или статьи.
- `<footer>` — нижняя часть сайта с контактами, ссылками и подпиской.

Ссылки вроде `<a href="#contact">` ведут к элементу с `id="contact"` на этой же странице. Поэтому пункты меню прокручивают страницу к нужному разделу. Ссылка подходит для перехода, а `<button>` — для действия, например для открытия мобильного меню или отправки формы.

### Что означают атрибуты

Атрибуты — это дополнительные настройки внутри открывающего тега. Например, в `<img src="photo.webp" alt="Портрет дизайнера">` атрибут `src` указывает файл картинки, а `alt` даёт текстовое описание, если изображение не загрузилось или его читает скринридер.

- `id` — уникальное имя элемента. По нему работают ссылки-якоря и связи между элементами.
- `class` — имя или набор имён для оформления CSS и поиска элементов в JavaScript. Классы `.header`, `.contact-form` и другие здесь в основном помогают задавать внешний вид. JavaScript отдельно использует классы `.header__button`, `.header`, `.header__toggle`, `.hero-action`, `.contact-form`, `.footer-subscribe`, `.reveal-on-scroll`, `.is-visible`, `.active` и `.is-open`.
- `href` — адрес, куда ведёт ссылка. Значение `#home` означает переход к элементу с `id="home"`.
- `src` — путь к картинке или подключаемому файлу.
- `type="email"` — говорит браузеру, что поле предназначено для адреса почты; браузер может проверить его формат.
- `required` — не даёт отправить форму с незаполненным обязательным полем.
- `autocomplete="email"` — подсказывает браузеру, что сюда можно подставить сохранённый email.
- `defer` у `<script>` — просит загрузить JavaScript-файл, не останавливая разбор HTML, и выполнить его после разбора документа.
- `aria-label` — доступное имя элемента, то есть короткое объяснение его назначения для скринридера. Например, у круглой кнопки со стрелкой может не быть видимого текста; `aria-label="View UI/UX Design projects"` объясняет, куда она ведёт. Это не меняет внешний вид и не заменяет обычный видимый текст там, где он нужен.
- `aria-labelledby` — связывает область с заголовком по его `id`. Например, `aria-labelledby="contact-title"` говорит, что название секции контактов находится в заголовке с `id="contact-title"`.
- `aria-expanded` — сообщает, раскрыт ли элемент или меню. У мобильного меню значение меняется с `false` на `true` при открытии.
- `aria-controls` — указывает, каким элементом управляет кнопка. У кнопки меню это список навигации.
- `aria-hidden="true"` — скрывает декоративный элемент от скринридера. На странице это используется, например, для второго повтора бегущей строки, чтобы одинаковый текст не читался два раза.
- `aria-live="polite"` и `role="status"` — помогают скринридеру спокойно объявить сообщение формы после отправки, не заставляя пользователя искать его глазами.

У декоративных изображений обычно `alt=""`: скринридер пропускает их, потому что они не добавляют важной информации. Для содержательных изображений указан описательный `alt`. Класс `.visually-hidden` прячет подпись визуально, но оставляет её доступной скринридеру — так устроены подписи email-полей.

## 2. JavaScript: что происходит на странице

JavaScript лежит в `main.js`. Он не строит всю страницу заново, а находит уже существующие HTML-элементы и добавляет им поведение: открывает меню, отмечает выбранные ссылки, отправляет формы и показывает элементы при прокрутке.

### Как читать синтаксис в этом файле

```js
const header = document.querySelector('.header')
```

`const` создаёт переменную, имя которой нельзя переназначить. `document` — текущая HTML-страница. `querySelector()` ищет первый элемент, подходящий под CSS-селектор `.header`, то есть элемент с классом `header`. Для поиска всех совпадений используется `querySelectorAll()`.

```js
const setNavigationOpen = isOpen => {
  header.classList.toggle('is-open', isOpen)
}
```

`setNavigationOpen` — функция. Стрелка `=>` — короткая запись функции, а `isOpen` — переданное ей значение. `classList.toggle(name, true/false)` добавляет класс, если передано `true`, и убирает, если `false`. Поэтому CSS может показать меню, когда у шапки есть `.is-open`.

```js
navigationToggle?.addEventListener('click', () => {
  setNavigationOpen(true)
})
```

`addEventListener()` подписывает элемент на событие. Здесь событие — щелчок мышью или нажатие на кнопку. `?.` называется optional chaining: если кнопка не найдена и значение равно `null`, обработчик не запускается и код не падает на этой строке. `{ ... }` ограничивают блок кода функции.

`event` — объект с данными о событии. Например, обработчик `keydown` смотрит на `event.key`, чтобы закрыть меню клавишей Escape. `if (...)` выполняет код только при истинном условии. `forEach(...)` проходит по найденным элементам и запускает действие для каждого.

### Меню и выбранные ссылки

Скрипт находит кнопки меню `.header__button`, саму шапку `.header` и кнопку `.header__toggle`.

Когда нажимают на меню-гамбургер, функция `setNavigationOpen()` переключает класс `.is-open` у шапки, меняет атрибут `aria-expanded` и обновляет доступное имя кнопки: «Open navigation» или «Close navigation». CSS по `.is-open` показывает список меню и превращает три полоски кнопки в крестик.

Нажатие на пункт меню снимает `.active` с остальных пунктов, добавляет его на выбранный и закрывает мобильное меню. Клавиша Escape тоже закрывает меню. Если ширина окна становится десктопной — от 901 пикселя — меню закрывается. Похожим образом при нажатии на одну из ссылок `.hero-action` класс `.active` переключается на неё.

### Формы и EmailJS

У формы контакта и формы подписки есть обработчик события `submit` — это отправка формы. Сначала `event.preventDefault()` отменяет обычную перезагрузку страницы. Затем `form.reportValidity()` просит браузер проверить обязательные поля, в том числе формат email. Если проверка не пройдена, отправки не будет.

`emailjs.sendForm(serviceId, templateId, form)` отправляет значения формы через подключённый сервис EmailJS. Пока запрос выполняется, скрипт пишет в область статуса «Sending...». После успешного ответа показывает благодарность и очищает форму методом `form.reset()`. Если запрос не удался, `.catch(...)` выводит сообщение об ошибке и записывает подробности в консоль.

В `index.html` подключён SDK EmailJS и указан публичный ключ; в `main.js` находятся ID сервиса и шаблона. Настройки этих значений должны совпадать с проектом EmailJS. Отправка зависит от стороннего сервиса и интернета; своего серверного обработчика форм здесь нет.

### Появление при прокрутке: `IntersectionObserver`

`IntersectionObserver` — встроенный в браузер инструмент: он сообщает JavaScript, когда элемент появляется в видимой области страницы. В коде он используется для плавного появления заголовков, карточек, фотографий, форм и других блоков.

Сначала `querySelectorAll()` собирает элементы по списку CSS-селекторов в `motionTargets`. Затем проверяется условие:

```js
if ('IntersectionObserver' in window) {
  // включить анимацию появления
}
```

Так код сначала убеждается, что браузер умеет работать с `IntersectionObserver`. Если умеет, целям добавляется класс `.reveal-on-scroll`, а корневому элементу `<html>` — `.motion-ready`. CSS использует эти классы, чтобы начать элементы прозрачными и немного сдвинутыми вниз.

Задержка появления задаётся так:

```js
element.style.setProperty('--reveal-delay', `${(index % 3) * 90}ms`)
```

`style.setProperty()` устанавливает CSS-переменную прямо на элементе. `index` — номер элемента в списке. Остаток от деления `index % 3` повторяет числа `0`, `1`, `2`, а умножение на `90` даёт задержки `0ms`, `90ms`, `180ms`. Обратные кавычки создают шаблонную строку, а `${...}` вставляет в неё вычисленное значение. В CSS переменная читается как `var(--reveal-delay)`. Так соседние элементы появляются не все одновременно, а маленькой очередью.

Наблюдатель настроен с `threshold: 0.12`: элемент считается появившимся, когда в области просмотра видно примерно 12% его площади. `rootMargin: '0px 0px -36px 0px'` немного сдвигает нижнюю границу области наблюдения, чтобы анимация начиналась чуть позже. Когда цель пересекает границу, обработчик добавляет `.is-visible`, а `unobserve()` прекращает наблюдать за ней: повторно запускать это появление не нужно.

Если `IntersectionObserver` не поддерживается, класс `.motion-ready` не добавляется. Поэтому CSS не прячет содержимое и страница остаётся читаемой даже без этой анимации.

## 3. CSS и SCSS: как страница выглядит и двигается

CSS отвечает за внешний вид: цвета, размеры, расположение блоков, адаптацию к телефону, состояния при наведении и анимации. SCSS — это CSS с дополнительными удобствами, например вложенными правилами и разделением на файлы.

`styles/style.scss` — главный SCSS-файл. Он подключает отдельные файлы из `styles/scss/`: у каждого своя часть страницы — шапка, hero, услуги, опыт, портфолио, отзывы, контактная форма, блог, подвал, адаптивность и движение. После компиляции получается `styles/style.css`, именно он подключается в HTML.

В `styles/normalize.css` лежат общие настройки: базовые отступы, шрифт, плавная прокрутка, размерная модель `border-box` и CSS-переменные цветов. Например, `--main-color` — оранжевый акцент, а `--secondary-color` — тёмный цвет текста. Повторно использовать цвет удобно через `var(--main-color)`.

### Псевдоклассы: состояния элементов

Псевдокласс — это способ выбрать элемент не только по имени, но и по его состоянию или месту среди соседей. Он пишется с одним двоеточием.

- `:hover` — курсор находится над элементом. В проекте так подсвечиваются ссылки и карточки, увеличиваются картинки, а у логотипа меняется подпись.
- `:focus-within` — фокус клавиатуры находится на самом элементе или внутри него. С ним карточки услуг и проектов раскрывают нужное состояние и без мыши.
- `:focus-visible` — элемент получил фокус, который нужно заметно показать, обычно при переходе клавишей Tab. Контур помогает понять, где сейчас находится клавиатурный фокус.
- `:has(...)` — выбирает элемент, если внутри него есть элемент, подходящий условию. Например, `.hero-actions:has(.hero-action-secondary:hover)` меняет оформление всей группы кнопок, когда наведён курсор на вторую кнопку.
- `:first-child`, `:last-child`, `:nth-child(2)` — выбирают первый, последний или, например, второй дочерний элемент. В проекте ими выбираются полоски мобильного меню, маркеры временной шкалы и последняя карточка в ряду.
- `:not(:last-child)` — выбирает все элементы, кроме последнего; так пунктир временной шкалы продолжается между этапами, но не рисуется после последнего.
- `:last-child:nth-child(odd)` — выбирает последнюю карточку, если она одновременно стоит на нечётной позиции; на планшете это помогает центрировать одинокую карточку в ряду.

Класс `.active` — не псевдокласс. Это обычный класс, который JavaScript добавляет выбранной кнопке.

### Псевдоэлементы и адаптивность

Псевдоэлемент пишется с двумя двоеточиями и позволяет добавить декоративную деталь без нового HTML-элемента. `::before` и `::after` используются для слоёв карточек услуг, затемнения изображения проекта, пунктирных линий временной шкалы и маленьких точек возле автора/даты статьи. `::placeholder` задаёт стиль текста-подсказки внутри поля. `::-moz-focus-inner` сбрасывает внутреннее оформление кнопки в Firefox.

Правила внутри `@media` меняют макет в зависимости от ширины экрана. При ширине до `900px` меню становится мобильным и несколько сеток перестраиваются. До `700px` блок найма переходит на одну колонку. До `600px` уменьшаются размеры и большинство карточек располагается в одну колонку. Это не отдельные страницы, а та же разметка с другой раскладкой.

`@keyframes` описывает шаги анимации. Например, `ticker-scroll` двигает ленту услуг, `timeline-pulse` слегка подсвечивает маркеры опыта, а `service-float` плавно перемещает декор.

Блок `@media (prefers-reduced-motion: reduce)` проверяет системную настройку пользователя «уменьшить движение». Если она включена, часть анимаций отключается или упрощается, а элементы появления сразу показываются.

### Запуск локально

Чтобы при изменении SCSS автоматически обновлялся CSS, в корне проекта выполните:

```bash
npm install
npm run sass:watch
```

После запуска можно открыть `index.html` в браузере или использовать локальный статический сервер. Если меняете стили, редактируйте файлы в `styles/scss/` и оставляйте скомпилированный `styles/style.css` обновлённым.
